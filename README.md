# 📝 Blog Platform - Front-End

Welcome to the client-side application of our Full-Stack Blog Platform. This is a responsive, modern user interface built to handle user authentication (OAuth & local), email verification flows, and full blog management (CRUD).

## 🚀 Features

*   **Secure Authentication UI:** Dual-mode login/signup supporting both Google/GitHub OAuth and email/password.
*   **Email Verification Flow:** Dedicated landing pages for account verification status.
*   **Blog Dashboard:** Create, read, update, and delete your own blogs with a rich text preview.
*   **Feed & Discovery:** Public feed to browse and read articles written by other creators.
*   **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop devices.

## 🛠️ Tech Stack

*   **Framework/Library:** React.js / Next.js
*   **Styling:** Tailwind CSS
*   **State Management:** Context API / Redux Toolkit
*   **API Client:** Axios (configured with interceptors for JWT handling)
